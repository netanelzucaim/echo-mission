# Fix plan: how each CVE would be fixed

Generated by `scripts/fix-method.py`. Do not edit by hand; rerun the script. It proposes a
method per CVE; the choice of which ones to fix, and the reasons, belong in the main README.

Image: nginx 1.25.5. Policy: optional modules are kept for compatibility.

| Method | Meaning |
|---|---|
| BACKPORT | Stay on this version and adapt the upstream patch to it |
| VERSION BUMP | Install the newer package version that already has the fix |
| REMOVE | Take the vulnerable component out of the image |
| ACCEPT | No fix exists; keep it, and list it as residual risk |
| INVESTIGATE | Not enough information to choose; needs reading |
| NONE | Not vulnerable in this build |
